# 实验四代码说明文档

## 1. 功能概述

本次实验在实验三初次迭代程序的基础上，使用面向对象思想重新设计了算术习题生成系统。程序主要由 `BinaryOperation` 类、`Exercise3_1` 类和运行入口 `project006` 组成，分别负责“单个算式的封装”“整套习题的生成与管理”“用户交互与程序启动”。

程序完成的主要任务如下：

1. 生成 100 以内的加法、减法或混合算式。
2. 保证减法结果不为负数、加法结果不超过 100。
3. 生成 50 道不重复的习题。
4. 按 5 列格式输出题目。
5. 输出对应参考答案。
6. 提供菜单，让用户选择加法、减法或混合题型。

## 2. 类的组成与作用

### 2.1 BinaryOperation 类

`BinaryOperation` 类用于表示一个“二元运算式对象”，也就是一道具体的算术题，例如 `32+5` 或 `18-7`。

它完成的任务是：

1. 保存一个算式的左操作数、右操作数、运算符和结果。
2. 按要求随机生成加法算式。
3. 按要求随机生成减法算式。
4. 随机生成加法或减法混合算式。
5. 提供获取算式各部分信息的方法。
6. 将算式转换成字符串形式，便于输出显示。

### 2.2 Exercise3_1 类

`Exercise3_1` 类用于表示“一套习题”，内部包含 50 个 `BinaryOperation` 对象。

它完成的任务是：

1. 生成 50 道加法题。
2. 生成 50 道减法题。
3. 生成 50 道混合题。
4. 检查新题是否与之前题目重复。
5. 按固定格式输出习题和答案。
6. 根据用户菜单选择调用不同的生成方法。

### 2.3 project006 类

`project006` 是实验四的程序入口，用来承接实验三的交互风格。

它完成的任务是：

1. 显示菜单。
2. 读取用户输入的题型选择。
3. 调用 `Exercise3_1` 对象生成对应习题。
4. 输出最终题目和答案。

## 3. 定义量与用法说明

### 3.1 BinaryOperation 类中的定义量

`UPPER`  
含义：运算结果和操作数允许的最大范围上界。  
定义：`static final int UPPER = 100;`  
用法：控制生成题目时所有数字都在 100 以内。

`LOWER`  
含义：运算结果和操作数允许的最小范围下界。  
定义：`static final int LOWER = 0;`  
用法：保证数字不小于 0。

`RANDOM`  
含义：随机数生成器。  
定义：`private static final Random RANDOM = new Random();`  
用法：生成随机操作数和随机题型。

`leftOperand`  
含义：左操作数。  
用法：保存一道题中的第一个数字，如 `32+5` 中的 `32`。

`rightOperand`  
含义：右操作数。  
用法：保存一道题中的第二个数字，如 `32+5` 中的 `5`。

`operator`  
含义：运算符。  
用法：表示当前是加法还是减法，可取 `'+'` 或 `'-'`。

`value`  
含义：运算结果。  
用法：在构造算式时就计算并保存结果，避免后续重复计算。

### 3.2 Exercise3_1 类中的定义量

`OPERATION_NUMBER`  
含义：习题总数。  
定义：`private static final short OPERATION_NUMBER = 50;`  
用法：规定每次生成 50 道题。

`COLUMN_NUMBER`  
含义：每行显示的题目数量。  
定义：`private static final short COLUMN_NUMBER = 5;`  
用法：控制输出格式，每行 5 题。

`operationList`  
含义：存放所有题目的数组。  
定义：`private final BinaryOperation[] operationList = new BinaryOperation[OPERATION_NUMBER];`  
用法：保存生成后的 50 个算式对象。

## 4. 主要方法与用法

### 4.1 BinaryOperation 类中的主要方法

`construct(int left, int right, char op)`  
作用：构造一个具体算式，并计算结果。  
用法：这是私有方法，只在类内部被调用，不直接给用户使用。

`generateAdditionOperation()`  
作用：随机生成一道 100 以内加法题。  
用法：返回一个 `BinaryOperation` 对象。

`generateSubstractOperation()`  
作用：随机生成一道 100 以内减法题。  
用法：保证被减数大于等于减数，结果不为负。

`generateBinaryOperation()`  
作用：随机生成加法或减法题。  
用法：混合题生成时调用。

`getLeftOperand()` / `getRightOperand()` / `getOperator()` / `getResult()`  
作用：访问对象内部数据。  
用法：供其他类读取算式信息。

`equals(BinaryOperation anOperation)`  
作用：比较两个算式是否相同。  
用法：在生成习题时用于去重。

`toString()`  
作用：返回不带结果的算式字符串，如 `32+5`。  
用法：供显示和拼接使用。

`asString()`  
作用：返回带等号但不带结果的字符串，如 `32+5=`。  
用法：用于输出习题。

`fullString()`  
作用：返回完整算式字符串，如 `32+5=37`。  
用法：用于输出答案。

### 4.2 Exercise3_1 类中的主要方法

`generateBinaryExercise()`  
作用：生成 50 道混合题。  
用法：内部循环调用 `generateBinaryOperation()`，并检查重复。

`generateAdditionExercise()`  
作用：生成 50 道加法题。  
用法：全部题目都为加法。

`generateSubstractExercise()`  
作用：生成 50 道减法题。  
用法：全部题目都为减法。

`generateExerciseByChoice(int choice)`  
作用：根据用户选择决定生成哪一类题目。  
用法：

1. `choice == 1` 生成加法题
2. `choice == 2` 生成减法题
3. 其他情况生成混合题

`contains(BinaryOperation anOperation, int length)`  
作用：检查新生成的题目是否已经出现在当前习题集中。  
用法：若重复则重新生成，保证题目不重复。

`formateAndDisplay()`  
作用：按要求格式输出题目和参考答案。  
用法：先输出练习题，再输出答案，每行 5 题。

## 5. 程序执行流程

程序运行流程如下：

1. 启动 `project006`。
2. 显示菜单，让用户选择加法、减法或混合。
3. 创建 `Exercise3_1` 对象。
4. 调用 `generateExerciseByChoice(choice)` 生成对应题目。
5. `Exercise3_1` 在生成过程中调用 `BinaryOperation` 对象产生单个算式。
6. 每生成一道题，都调用 `contains()` 检查是否重复。
7. 全部生成后，调用 `formateAndDisplay()` 输出题目与答案。

## 6. 本次代码完成了什么任务

这次新代码完成了以下任务：

1. 将实验三中“以过程为主”的做法改写为“以对象为主”的做法。
2. 把“一个算式”抽象成 `BinaryOperation` 类。
3. 把“一个习题集”抽象成 `Exercise3_1` 类。
4. 补全了资料中缺失的方法代码。
5. 实现了加法、减法、混合题三种生成方式。
6. 实现了 50 道题目的批量生成。
7. 实现了题目去重。
8. 实现了格式化输出和答案输出。
9. 保留了实验三中的菜单式交互习惯，使实验四与前面迭代过程自然衔接。

## 7. 总结

本次实验通过引入 `BinaryOperation` 和 `Exercise3_1` 两个类，将原来分散的题目生成逻辑封装到对象中，使程序结构更加清晰，职责划分更加明确，也更符合面向对象设计思想。与实验三相比，实验四不仅实现了相同的功能，还提升了程序的可维护性、可扩展性和复用性。
